# Старый движок (JS/WebView) vs новый (Rust) — один сценарий, одна машина (4 ядра, CPU-only)

Сценарий (`geo/perf/sim_bench.js` для JS, `shot ... "bench N"` для Rust): Россия воюет с 5 странами, N дивизий,
фронты по странам, 5 планов наступления, 300 игровых часов; сглаживание каждые 3 ч, заливка зон каждые 4 ч, линии разреза каждые 12 ч.

| Дивизий | JS мс/час | Rust мс/час | Ускорение |
|---|---|---|---|
| 200 | 14.37 | 4.95 | 2.9× |
| 600 | 18.36 | 6.41 | 2.9× |
| 1500 | 29.37 | 12.26 | 2.4× |

По системам (600 дивизий, мс за вызов): часовой тик 10.73 → 3.67; сглаживание захвата 12.23 → 3.01;
заливка зон 7.85 → 4.79; линии разреза 12.23 → 3.60.

Загрузка карты (все 3 уровня детализации + растр клеток): JS 4.4–6.3 с (играбельно через 2–3 с), Rust 0.67–0.76 с.
